# Contributing

This repository is a read-only mirror of the Arcade launchpad contracts,
published for integrators (aggregators, explorers, indexers, bots). The
sources are copied from the private Arcade monorepo at the commit named in
the README; they are not developed here and pull requests that change the
contracts will not be merged, since the deployed bytecode is immutable.

Issues are welcome for anything an integration needs: a question about the
hook's behaviour, an inaccuracy in the README, a missing address, a request
for an ABI or an example. Open an issue and it will be answered.
